Open by design

Anyone can check it, use it or build on it

  • Open code. Apache 2.0 on GitHub, with issues, pull requests and reviews in the open.
  • Open data. Datasets published on Hugging Face for download and reuse.
  • Open to AI assistants. An MCP server lets assistants such as Claude query the data directly.
  • Open standards. Meeting data compatible with the Council Data Project; place IDs from the Open Civic Data standard (OCD-ID).

Public records should stay public when they are made easier to use.

github.com/getcommunityone/open-navigator · 9

Everything is open. The code is Apache 2.0, and the work happens in public issues and pull requests. The datasets are published on Hugging Face. There is an MCP server, so an AI assistant can query the data directly instead of guessing. And the data follows existing civic standards, like the Council Data Project's meeting model and Open Civic Data identifiers, so it can connect to other civic tools rather than becoming another silo.
