Architecture: web_docs/docs/architecture.md · data sources: CITATIONS.md · 7

Five steps. Discover finds where each government posts its records. Collect pulls in agendas, minutes, transcripts and budgets, plus IRS nonprofit filings and Census data. Extract uses AI to turn long transcripts into structured decisions, votes, speakers and quotes. Model is where the data gets cleaned and joined, in dbt, in layers from raw to ready, including matching the same city or nonprofit across different sources. Serve puts it in a Postgres database behind an API, the web app, open datasets anyone can download, and an MCP server so AI assistants can query it directly.
