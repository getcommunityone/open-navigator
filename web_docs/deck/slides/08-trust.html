Trust

Rules that keep it honest

No made-up numbers

If data is missing, the app says it is missing. No placeholder figures, ever, and above all no invented dollar amounts or vote counts.

Evidence on every match

A filtered result shows the real passage that matched. No passage, no result.

The label matches the filter

The place named on the page is the place the data is filtered to, and the filter carries across pages.

Every source cited

Datasets, standards and research are credited with licences in CITATIONS.md.

These are written rules for every contributor and coding agent (CLAUDE.md) · 8

Civic data only works if people can trust it, so these are written rules in the repository, for every contributor and every AI coding agent. First, no made-up numbers: when data is missing the app shows that it's missing, because a made-up dollar amount is worse than nothing. Second, evidence on every match: if a result shows up because of a search term, the tile shows the real passage. Third, the label on the page always matches the filter actually applied. Fourth, every dataset and method is cited with its licence.
